# Karaoke Roulette
家族の次の歌い手と曲を選ぶ、日本語・ダークテーマのスマホ向けアプリ。React / TypeScript / Vite。バックエンドやAPIキーは不要です。

## 開発
Node.js 24 / npm を使用します。
```sh
npm ci
npm run dev
npm test
npm run build
```

抽選は人→曲の順で演出し、確定時のみ曲を使用済みにして履歴を保存します。一巡の未確定メンバーから均等に選び、全員が確定すると次の巡になります。曲がない人は除外されます。再抽選は未確定メンバー内で無制限です。手動確定も現在の巡からその人を消費します（すでに消費した人を手動で選ぶこともできます）。

設定から家族・曲を編集、使用済み曲をチェックして一括再追加できます。履歴リセットは履歴と巡の進行のみを初期化します。曲は自動で復活しません。データはブラウザのlocalStorageに保存され、端末間同期はありません。サイトデータの削除で失われます。初回はデモデータが入ります。

## GitHub Pages
リポジトリ Settings → Pages → Source を GitHub Actions に設定してください。mainへのpushでテスト・ビルド後に公開します。公開パスは /karaoke-roulette/ です。リポジトリ名を変更する場合はワークフローのbaseを変更してください。
